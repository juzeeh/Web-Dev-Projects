# Dating Website – PHP & Laravel

A full-stack dating platform designed to connect individuals based on shared interests, compatibility, and communication preferences. The application allows users to register, build profiles, find potential matches, and chat securely in real-time.

---

## Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, JavaScript, jQuery, AJAX  
- **Backend:** PHP (Laravel Framework)  
- **Database:** MySQL  
- **Version Control:** Git & GitHub  
- **Additional Tools:** Laravel Blade templating engine, Laravel Auth for user login/registration

---

## Features

- ✅ User registration & login (with secure authentication)
- ✅ Profile creation & editing
- ✅ Matchmaking system based on user preferences
- ✅ Browse/search for potential matches
- ✅ Send and accept connection requests
- ✅ Real-time chat using AJAX and jQuery
- ✅ Fully responsive UI (mobile-first design using Bootstrap)
